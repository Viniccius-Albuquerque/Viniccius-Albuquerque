## Sobre mim

Sou estudante de Ciência da Computação na UNICAP, interessado em desenvolvimento backend, construção de APIs e bancos de dados relacionais.

Busco transformar meus conhecimentos em projetos práticos, com atenção à organização do código, às regras de negócio e à persistência de dados.

- Desenvolvimento de aplicações com Python e outras linguagens.
- Estudo de APIs REST com FastAPI e validação de dados com Pydantic.
- Prática de SQL, modelagem de dados e integração com bancos relacionais.
- Aprendizado de testes automatizados e boas práticas de programação.
